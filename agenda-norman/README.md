# Agenda Norman García DOTI 2026

Aplicación HTML personal para seguimiento de actividades de Norman García, basada en el calendario DOTI 2026.

## Uso previsto

- Ver actividades en calendario y listado.
- Agregar actividades nuevas desde el navegador.
- Editar o eliminar actividades.
- Exportar respaldo JSON y CSV.

## Nota importante

Si se publica en GitHub Pages, los cambios agregados desde el navegador se guardan localmente en el navegador del usuario. Para conservar o mover los datos a otro equipo, se debe exportar el respaldo JSON e importarlo nuevamente.
